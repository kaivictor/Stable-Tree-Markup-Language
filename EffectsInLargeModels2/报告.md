
# 大模型对于STML、YAML、JSON支持的非严谨测试报告

本测试使用大模型`deepseek-v4-flash`测试了stml、yaml、json的生成、理解。对于yaml和json，默认大模型已经认识，对于stml提供stml规范。

## 测试内容

进行了以下测试:
1. 让大模型同时生成成对的stml↔yaml、stml↔json和yaml↔json，存放于test_data(test_data1)文件夹；
涉及脚本: generate.py
2. 使用Python的json库、PyYaml库和自建的stml库解析到大模型生成的json、yaml和stml->得到大模型生成json、yaml和stml的能力指标；
3. 复制有效的stml↔yaml、stml↔json和yaml↔json到test_data2文件夹；
涉及脚本: check_yaml.py、check_json.py、check_stml.py、
4. 对比成对的stml↔yaml、stml↔json和yaml↔json->得到大模型对json、yaml和stml的理解指标；
涉及脚本: check_stml_json.py、check_stml_yaml、check_yaml_json.py、check_type_ignore.py、collect_all_stats.py
5. 从test_data2中，随机挑选20个yaml、json和stml文件，交给大模型生成分别请大模型执行yaml->json和yaml->stml与json->yaml和json->stml与stml->yaml和stml->json，得到大模型生成yaml、json和stml，存放于test_data3文件夹；
涉及脚本: translate.py
6. 使用Python的json库、PyYaml库和自建的stml库解析到大模型生成的json、yaml和stml->再次得到大模型生成json、yaml和stml的能力指标；
7. 复制有效的yaml->json、yaml->stml、json->yaml、json->stml、stml->yaml和stml->json到test_data4文件夹；
涉及脚本: check_yaml.py、check_json.py、check_stml.py
8. 对比成对的yaml->json、yaml->stml、json->yaml、json->stml、stml->yaml和stml->json->得到大模型对json、yaml和stml的理解指标；
涉及脚本: check_phase2.py、check_type_ignore.py、collect_all_stats.py
（check_json2stml.py、check_stml2json.py、check_stml2yaml.py、...，未使用）


## 局限因素

1. stml提供了规范，而yaml、json没有，避免了提示词过长和规范先后的影响，但也存在认知不公平；
2. 大模型生成的有效数据可能过少，进一步导致结果的代表性不足；
3. 成本关系，只对DeepSeek-v4-flash进行测试，每组数量20；
4. 随机抽查的文件忽视了类型不支持问题，这会导致有效生成数量减少；
